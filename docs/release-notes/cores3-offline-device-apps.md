## 解消した競合

- KoeAct特徴抽出配列約47KBの内部RAM常駐をやめ、認識時だけPSRAMへ確保して解放。2回目の前後で内部空き100,567→100,971bytes、PSRAM差364bytes。
- 見守りの自動撮影中に睡眠タイマーがリセットされる問題を修正。
- HTTP keep-aliveで残りTCP送信容量を失う問題を修正。ACK追加通知なしで20連続POSTを検証。
- 音声一覧は保存済み索引を使用し、実機で15.418秒→0.028秒。旧音声の全走査は明示的な再検出操作に分離。
- AIテキストのTLSを専用Workerへ分離。SD履歴書込みに合わせた接続保持と待ち時間を設定。
- 接続切れでは状態の読取りだけを最大2回再接続。文章の送信操作は再実行しない。送信応答を失った場合も同じIDの結果を確認。
- XiaoZhiの長い文章は、短い起動要求と文章を読む専用MCPツールで渡す。公開するツールは読取り専用の1件だけで、家電・サーボ・カメラ・記憶の変更操作は公開しない。
