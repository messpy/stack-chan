# 放置時の寝顔を現在の音声修正版へ復元

Release impact: patch

以前の統合ブランチに存在した寝顔を、音声修正・診断・待機負荷軽減を含む版へ戻します。
通常の顔で10分無操作ならうとうと、30分ならZzz付きの寝顔になります。
頭・顔のタッチ、認識した発話、会話開始操作、オフライン操作で通常表示へ復帰します。
顔を覆う表示だけを追加し、音声接続停止、再起動、サーボ操作は行いません。

返答待ち・音声再生・撮影・モニター・オフライン再生・設定画面では寝顔を抑止します。
処理中の時間は無操作時間に含めず、処理後に改めて計時します。
犬顔・画像顔など通常顔以外とカスタム顔には寝顔を重ねません。
時刻補正に影響されない単調時間を使い、遅延したタイマーと時刻カウンターの周回に対応します。
段階（awake/drowsy/deep）、表示段階、無操作時間は既存の診断ログで確認できます。

10分・30分はソフトウェアの仮想時間テストで確認します。実機の長時間遷移と
発話・タッチの物理動作は別途受入が必要です。寝顔復元を音質・RAM根本問題の解決とは扱いません。
