# 内蔵RAM不足が続いた場合の音声停止

Release impact: patch

会話または文字起こしの開始・再接続で内蔵RAM不足が3回連続した場合、
リソースを解放して自動再試行を停止します。内蔵RAM不足の表示と、
他の処理を終了して会話または文字起こしをOFF→ONにする手順を表示します。
一時的な不足には従来の待機付き再試行を2回行います。

診断APIとPC診断保存に連続失敗回数・停止状態を追加しました。
Wi-Fi復帰、カメラ・モニターからの復帰、オフラインからの復帰は停止を解除しません。
RAM保護閾値（Opus 112KiB / 最大連続24KiB）は変更しません。

この修正はIssue #40の無制限なRAM不足再試行への対応です。
RAM消費元、リークの有無、実機の音質改善を確定するものではありません。
