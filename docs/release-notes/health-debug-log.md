# RAM・音声・画面の定期診断ログ

Release impact: patch

RAM（内蔵・PSRAM・最大連続空き）、音声入出力／送信／ASR、バッファ量、
再接続、撮影、Wi-Fi接続有無、ステータスバーの各表示状態を既存の
デバッグログへ記録します。10秒ごとに状態を観測し、状態変化時と30秒ごとに
記録します。短時間の変化はまとめられ、全イベントを逐次保存するものではありません。

記録は既存のPSRAM上の容量制限付きログを使います。USB未接続でも記録し、
上限では古い記録から消えます。電源断・再起動では失われるため、長期保存には
既存のUSBログ採取またはPCの認証付きLAN診断JSONL採取を使ってください。
SDへの常時書込みや録音は追加しません。

新しいhealth記録には会話本文、音声、APIキー、SSIDや機器識別子を含めません。
通常は1レコード、診断値が大きい場合は2レコードに分け、各ネイティブログ枠に
完全なJSONを収めます。診断の履歴配列や音声コールバック内の計測は追加しません。

顔画面の時計・操作ボタンが4秒で隠れる既存仕様は維持します。
電池・Wi-Fiまで消える実機症状の原因は未確定です。表示状態の診断は読取りのみで、
これを実機の表示修正・RAM不足解消・音質改善の完了とは扱いません。
