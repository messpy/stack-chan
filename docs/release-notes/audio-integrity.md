# Archive音声出力と送信状態の修正候補

Release impact: patch

- CoreS3のArchive会話で、非同期I2S再生キューのネイティブ処理を排他化し、短い書込みをエラーとして停止する。
- 音声レート変更時の古い再生タイマーと、出力生成途中のエラー時の資源解放を修正する。
- XiaoZhi文字起こし専用時、応答の抑止後に音声送信を再開する。緑LEDは直近の音声送信実績に連動する。
- 認証付き診断APIとPC保存に入力・送信・ASR・再生・欠落・再接続の数値を追加する。音声や会話本文は追加記録しない。

実機で報告された異音の原因はログがなく未確定。実機未検証のためDraftであり、音響問題・RAM不足・サーボ問題の解決は保証しない。
