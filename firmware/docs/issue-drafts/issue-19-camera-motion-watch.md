# Issue #19: オフライン画像差分監視カメラの安全設計

> **Draft / planning only.** 実装前の確認と合格条件を追跡する差分です。このコミットで本体機能、DB、設定、GPIO、Flashは変更しません。

## 目的と範囲
CoreS3単体で低負荷な画像差分監視を行い、ネットワークは通知時のみ使用する。初期OFFと同意・表示を必須とする。

## 調査対象
- `firmware/host/app/lan-archive.js`
- `firmware/host/app/archive-lan-monitor.js`
- `firmware/host/app/archive-vision.js`

## 段階実装
1. 撮影排他/フレーム寿命/RAM/音声・サーボ競合の実装を監査する
2. RGB565→低解像度輝度差・照明補正・ROI・連続検出の純粋関数をテストファーストで実装する
3. busy時スキップ/停止時リソース解放・ローカル通知・オプトイン外部通知を段階実装する

## 完了判定
- [ ] 監視は初期OFF、操作中のみ撮影、顔・睡眠表示に干渉しない
- [ ] 照明変化・カメラ移動・ノイズで誤検知を抑制
- [ ] SD無し・ネット断・手動写真と音声会話・24/72時間の連続試験

## 前提・安全
実機撮影の既存不具合#33およびRAM不足#40を先に評価。監視映像はアップロードしない。

- 本文と実機実装の差分を継続追跡し、未実装のAPIを存在すると表示しない。
- Read-only Firstで依存・ピン・保存先を確認し、設定やデータを変更する前に影響範囲を明確化する。
- SD/SQLite/Flashへの変更時は完全バックアップ、再実行時の整合性検証、ロールバック手順を設ける。
- 秘密トークン、私有manifest、音声・写真、学習済み個人情報は公開しない。
- ユニットテスト、CI、CoreS3ビルド、実機検証のエビデンスが揃うまでDraftを維持する。

## 2026-11-08: P1画像差分プロトタイプ追加

`firmware/scripts/lib/archive-camera-watch-policy.mjs` は、ESP32/カメラを一切触らない**Node検証専用の純粋関数**。RGB565LEからの小サイズグレースケール画像生成、輝度差の中央値補正、ROI、変化比率、2連続検知、5分クールダウンを実装し、同一画像/照明変化/局所移動/ROI/閾値のテストを追加。

```bash
cd firmware
node --test scripts/lib/archive-camera-watch-policy.test.mjs
```

制約: **ファームウェアmanifestには追加していない**。監視UI・撮影スケジューラ・通知・保存機能は未実装。検知閾値は暫定で、カメラ移動/自動露光/サーボ動作を実機で確認しない限り誤検知を防げたとは言えない。既存撮影不具合#33とRAM不足#40の修正を優先。
