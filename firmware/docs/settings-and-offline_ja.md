# 本体設定と自動オフライン

本体の「設定」に機能を集約しています。内部画面はアプリ一覧に重複表示しません。

- 会話・AI：会話モード、AIモデル、話す人の選択・登録。
- 音量・アラーム：音量、タイマー、新規アラーム、予約一覧・解除。
- Wi-Fi・接続：Wi-Fiを設定、スマホで操作（同じWi-Fi）、本体へ直接接続、接続状態。
- オフライン：自動切替、手動の本体モード、日時設定。

自動切替は既定でONです。変更は既存の暗号化SD設定に保存します。PCへのUSB接続と通常のWi-Fi接続が両方なくなった場合、約10秒後に本体モードを開き、クラウド会話を停止します。起動から最初の約30秒は接続を待ちます。充電器やモバイルバッテリーだけのUSB接続はPC接続に含めません（ESP-IDFのUSB SOF検出）。Wi-Fi設定用APの稼働中、録音・撮影・音声再生・アラーム中は切替を待ちます。

再接続で勝手に会話やマイクを開始しません。会話を再開するには明示的に会話モードをONにしてください。AIの選択、人物情報、既存のアラームは変更しません。オフラインではローカル合成音声・ボタン操作・時計・タイマー・アラームを利用でき、自由な音声認識・クラウドAI会話は利用できません。

認証済みUSB/LAN RPCの `/offline/auto` は状態（enabled / usb / wifi / active）を返します。args.enabledを真偽値で指定すると設定を保存します。activeは自動切替を実行した状態であり、マイク状態ではありません。

「設定 → 情報取得 / 本体の状態」は次の3ページを「次へ」で切り替えます。2秒ごとに更新し、「再取得」でも更新できます。新しい接続・音声送信は開始せず、現在の状態を読む画面です。

- Wi-Fi・USB：接続、IP、電波強度、PC接続、自動切替設定。
- AI：選択サービス、設定有無、会話モード、接続・聞き取り・再試行などの状態、エラー有無、モデル。
- 音声・本体：音量、聞き取り・再生状態、音声イベント回数、時計設定。

エラーの詳細はログで調査します。情報画面には認証トークン・APIキー・Wi-Fiパスワードを表示しません。

## ミニアプリと設定の移動

ミニアプリ一覧の「タイマー」「アラーム」は本体のボタンだけで操作できます。クラウド接続や音声認識は不要です。アラームは本体の日時を先に合わせてください。

タイマーは10秒・1分・3分・5分を選び、±1分で調整して「開始」を押します。登録後は残り時間を表示し、開始を無効にして同じ操作による重複登録を防ぎます。別の時間を選ぶと次の予約を作れます。「予約一覧・解除」で既存予約を確認・解除できます。アラームは時刻と一度／毎日を選び保存します。こちらも保存後の連打を無効にします。

設定画面左上の矢印は直前の画面へ戻ります。同じWi-Fiでの操作QRは1つに集約しました。「本体へ直接接続」は本体のアクセスポイントを使う別の経路です。「スマホでAIを設定」は同じLANの操作ページ内の会話設定を直接開きます。

AIの選択と会話の開始・停止を分離しました。会話モード内の「AIを選ぶ」は選択画面を開き、押すだけで別のサービスへ切り替えません。AI選択画面から会話が勝手に始まることもありません。

## 動作確認

右のメニューに並んでいた表情・顔・LED・サーボ・音声などのデモ項目を外し、「設定 → 動作確認」に集約しました。各項目か「まとめて確認」を選びます。顔を表示したまま、画面下部に進行・停止・戻るを表示します。実行完了は物理的な見た目や音まで自動保証する意味ではありません。実物も確認してください。「前回の結果」で項目ごとの結果を読めます。

1. 表情：通常・うれしい・おこる・かなしい・ねむい・あつい。
2. サーボ：左右・上下へ動かし、開始位置へ戻してトルクを解除。
3. LED：赤・緑・青・虹色、最後に消灯。
4. 音声認識：Wi-Fiと設定済みの会話サービスが必要。接続後、最大約15秒話しかけ、認識文字を結果に表示。XiaoZhiはXiaoZhi、GeminiとOllamaの音声部分はGeminiを使います。試験用の認識文字を会話履歴や人物プロフィールには保存しません。終了・停止・エラーでマイクと接続を閉じます。
5. 音声：現在の音量で本体合成音声を読み上げ。

開始時はクラウド会話を停止し、勝手に再開しません。停止は現在の動作の区切りで反映し、以後の項目を実行しません。表情は通常へ、LEDは消灯、サーボは開始位置へ戻します。処理中に自動オフライン画面へ割り込みません。診断の開始・終了・失敗は `[checks]` ログへ記録し、認識内容や資格情報は記録しません。

## デバッグログ

拡張ファームウェアは通常ビルドでも `trace()` をPSRAMの128件リングへ記録します。メインVMとGeminiワーカーに出力先を設定し、ESP-IDFのログコールバックも同じリングへ集めます。起動時のreset_reasonを記録します。USBへの送信は待ち時間0の小さいイベントに分割し、詰まった場合は後で再試行します。

USB接続中はPCのhubがデバッグイベントと通常のUSB出力を読み、認証情報・会話本文を伏せて `hub/logs/diagnostic.log` にローテーション保存します。Codexはこのファイルと認証済み `/api/logs` から取得できます。`/debug/status` は queued / dropped / truncated / usbRetries を返します。droppedはリングの上書き件数、truncatedは長い記録の切り詰め件数、usbRetriesはUSB送信を後回しにした回数です。

本体リングはRAMなので、電源断・再起動で消えます。SDへのログ保存ではありません。USBがない間に128件を超えた記録は古い順に上書きされます。1件は最大2047バイトです。ロガー初期化前の起動出力、ハードクラッシュ時にUSBへ届かなかった出力、コンパイルで削除されたSDKログを後から復元することはできません。「全ログを無制限・無欠損で保証する」ものではありません。

USBへのログ排出は、PCから認証済みの最初の要求が届いた後に開始します。接続ケーブルだけを検知して受信準備前に起動ログを消費しません。USB抜去後は再認証を待ちます。PC側の定期的な状態取得の成功記録はpollCountsへ集約し、本体のデバッグ記録や失敗ログが定期取得メッセージで埋まるのを防ぎます。

## 画面取得と表示確認

`archive-screen` はCoreS3のILI9341描画経路をミラーし、PSRAMに320×240 RGB565の表示内容と転送用スナップショットを保持します。SDK本体やLCDドライバーのソースは変更しません。Piuの描画完了を待って固定した後、最大8192バイトずつ転送するため、吹き出し消去やアニメーションで1枚の途中の内容が変わりません。通常のJPEGカメラ撮影とは別の機能で、SDやAIへ画像を送りません。

認証済みRPC `/screen/begin`・`/screen/read` でフレームを取得し、PCのhubは `/api/screen.png` でPNGを返します。`screen_capture.py --output /絶対パス/画像.png` で保存できます。`/screen/show` は既知の画面のみ開きます。会話・録音・撮影・アラーム中の画面切替は拒否します。`/screen/tap` は認証済みの座標タップをPiuの実際のタッチ入力へ渡し、画面確認や動作検証に使用します。

物理的なLCD・配線・バックライトの故障まではこの画像から判定できません。表示中の個人情報が写る場合があるため、取得画像はGitへ入れず、必要な検証画像だけ共有します。

ステータスのWi-Fiは5段階の `WiFi 1`〜`WiFi 5` とし、未接続・強度不明は `WiFi 0` です。バッテリーをWi-Fiと同程度の高さに小型化し、同じ行の左端に常時表示し、その右にWiFi強度を表示します。音量の大きな%文字もフォントに含めています。

オフラインタイマーは、1つの開始ボタンから登録できるのを1回に限定しています。SD保存に成功した時点で通常の選択肢へ戻り、遅れて届いたタップ終了や読み上げ失敗を理由に同じ開始ボタンから再登録しません。明示的にもう一度「タイマー」を選べば新しい予約を作れます。作成・通知ログには予約IDを残し、二重作成と再表示を区別できます。

バッテリーは20×12ピクセルで左上に表示し、その右にWiFiを配置し、時計・メニューの4秒タイムアウトとは独立して更新します。右のメニューも上部14ピクセルを避け、WiFiと電池を隠しません。通常画面へ戻す確認操作・設定への移動・USB/Wi-Fiの再接続では、残っていたオフライン用ボタンを閉じます。オフライン操作は明示的に開いた時、または自動オフライン切替時に表示します。接続が戻っても会話やマイクは自動で有効にしません。

バッテリーは最も左、その右にWiFi強度を並べています。いずれも上部の小さい常時表示です。

アラーム・タイマーの通知中は、虹色LEDに加え `archive-alarm-motion.createAlarmDance` が首を小さく左右・上下に動かします。停止または音の終了でダンスを終了し、通知開始時の角度へ戻してトルクを解除します。サーボ異常は通知音を中断せずログへ残します。動作中のサーボ位置ポーリングは半二重バスへ干渉するため、実機確認では停止前後だけ位置を取得します。

## 声での人物登録

「話す人を選ぶ・登録」→「新規登録（声）」で、待機タイマーを待たず音声サービスへの接続を開始します。準備中は接続待ちと表示し、マイク準備後に「いま、お名前を話してください」へ切り替わります。登録中はAIの挨拶を送らず、名前の発話と重ねません。名前を認識したらマイクを閉じ、確認ボタンを押した時だけプロフィールを保存します。聞き取り待ち中も「声で聞き直す」「キャンセル」を使えます。接続・マイク準備・名前認識の成否をログに残しますが、名前本文は記録しません。
