# 会話OFFの動作

2026-11-01: 起動時にAPIキー／クラウド登録の有無だけで会話をONに戻していたため、ユーザーがOFFにしても再起動後にXiaoZhiの無言タイムアウト案内と再接続が繰り返される経路があった。

起動時は保存された `chatMode` を尊重する。起動音声を待つ間にOFFにした場合も、待ち合わせ後にONへ戻さない。閉じたセッションからの入力レベル・口パク・表情イベントも無視する。

PCの停止操作は旧PC会話と本体会話を両方停止する。SD同期が保持する処理全体のロックを待たず、USBのコマンド単位ロックで `/chat/stop` を実行する。ファイル同期が長くてもOFFがその完了まで待たされることを避ける。

確認: 話者・会話テストで、保存OFF／起動音声中のOFF／保存ONの復元を確認。PCテストで同期ロック保持中にも本体停止へ到達し、旧会話も停止されることを確認。

実機: 2026-11-01 23:41 にOFF応答とマイク停止を確認。更新 `20261101-234138-18550` 成功後、再起動した本体の `/chat/status` を繰り返し確認し、`enabled:false,state:off,busy:false` を維持。確認後PCのUSB管理サービスを復帰する。
