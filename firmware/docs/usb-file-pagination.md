# USB経由のSD一覧

`/files` の全件送信は、写真・録音・会話JSONが増えるとUSBの1応答20KB上限を超える。上限を増やす代わりに、PC側の同期・会話録音取得は `/files/page` を使う。

入力は `{offset:0,limit:50}`、返却は `{items:[{name,size}],next:50}`。終端は `next:null`。各ページは件数と保守的な文字列サイズ見積もりで制限される。読み取りのみでファイル内容を変更しない。

PC側 `file_pages.read_file_pages` は連続するオフセットを検証しながら全件取得する。旧ファームウェアの全件応答へはフォールバックしないため、本体とPCサービスを一緒に更新する。LANブラウザの既存 `/files` は維持する。

テスト: 1200件・長い名前でも全件が一度ずつ返り、USB上限以内。空フォルダ・無効な継続値を確認。実機のSD一覧も更新後に確認する。

実機確認（2026-11-01、更新 `20261101-233330-14485`）: SD内761件を16ページでUSB取得。最大応答3370バイト、同名の重複0件、上限超過なし。読み取り後にUSB管理サービスを復帰。
